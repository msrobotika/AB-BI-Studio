Guardado y privacidad

«Exportar proyecto» descarga un archivo .abbi con registros, filtros, columnas calculadas y gráficos. Además puedes guardar y recuperar una copia en el almacenamiento de este navegador; esta segunda opción debe accionarse expresamente. No almacena contraseñas ni cifra los datos.

Guía rápida

  1. Importa un CSV / TSV / JSON o utiliza la demo incluida.
  2. Aplica filtros y haz clic sobre los gráficos para seleccionar categorías.
  3. Haz clic en «Editar» de una visualización para modificarla; exporta SVG o CSV desde ella.
  4. Abre «Explorador» para ordenar registros y crear columnas derivadas.
  5. Abre «Perfil de datos» para detectar ausencias, categorías y rangos.
  6. Exporta un proyecto .abbi y recupéralo después desde «Abrir proyecto».

Límites y alcance real

No abre PBIX, PBIP, XLSX, ni reproduce DAX/Power Query. No hay relaciones entre tablas, autenticación, refresco de orígenes ni conectores industriales. Es un prototipo local; no un sustituto certificado de Power BI. El PDF utiliza la función de imprimir del navegador.

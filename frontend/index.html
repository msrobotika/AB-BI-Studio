    AB-BI Studio 0.4

    Proyecto de análisis local con modelos relacionales, Excel multihoja, medidas DAX parciales, paneles de control y SQL de solo lectura.

    Se incluye el editor clásico v0.2 en Abrir editor v0.2. Los dos modos tienen proyectos independientes; exporta e importa los datos para cambiar de espacio.
    Los datos se guardan en data/workspace.json en este ordenador y se exportan SIN CIFRAR dentro del archivo .abbi. No se publican en Internet. El servidor escucha únicamente en 127.0.0.1.

    Compatibilidad

    Importa proyectos .abbi v1/v2 y convierte sus registros a un modelo de una tabla. La compatibilidad con archivos .pbix y DAX completo no está implementada. Excel .xlsx: todas las hojas no vacías se incorporan como tablas individuales.

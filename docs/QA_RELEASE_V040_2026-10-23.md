## Ensayo real en un entorno limpio

Workflow: .github/workflows/qa-release-v040.yml

En **Windows y Ubuntu con Python 3.13**, GitHub Actions descarga ambos activos publicados mediante GitHub CLI y ejecuta:

    python -m py_compile scripts/qa_official_release_v040.py
    python scripts/qa_official_release_v040.py --assets-dir <carpeta de descarga>

El script:
1. Verifica el hash SHA-256 contra el activo oficial y el CRC/estructura segura del ZIP.
2. Comprueba el MANIFEST.sha256 interno y la presencia de README, LICENSE, requisitos y lanzadores.
3. Crea **un venv nuevo** fuera del repositorio e instala los requirements incluidos EN LA RELEASE (necesita Internet).
4. Arranca `run.py` dentro del ZIP descomprimido con un puerto loopback elegido para el ensayo.
5. Confirma `/api/health` = versión 0.4.0, carga del frontend, y subida multipart del `examples/datos_para_limpiar.csv` de la distribución.
6. Verifica cuatro filas reales, columnas, perfil de datos y tabla incorporada al modelo semántico; detiene el proceso y elimina temporales.

Los tests existentes de `.github/workflows/ci.yml` se encargan de transformaciones, DAX parcial, API, persistencia y Chromium del **código actual**; no deben confundirse con la versión descargada v0.4.0.
